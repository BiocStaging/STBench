# Plot CCC sender-receiver communication

Plot CCC sender-receiver communication

## Usage

``` r
plot_ccc_sender_receiver(ccc_result, methods = NULL, method_order = NULL)
```

## Arguments

- ccc_result:

  Output from run_ccc().

- methods:

  Optional methods to include.

- method_order:

  Optional method order.

## Value

A ggplot object.
